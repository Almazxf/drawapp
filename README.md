# DrawApp — Portable Vector Editor

Приложение для рисования векторных схем. Работает без установки (portable .exe).

## Возможности

- **Фигуры**: квадрат/прямоугольник, круг, овал, треугольник, ромб, звезда
- **Линии**: прямая линия, стрелка
- **Заливка**: цвет + прозрачность
- **Обводка**: цвет + толщина
- **Текст** внутри любой фигуры (двойной клик)
- **Бесконечный холст** — скролл колесом, зум колесом мыши
- **Сохранение проекта** (.drawapp файл, редактируемый)
- **Undo/Redo** (Ctrl+Z / Ctrl+Y)

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| V | Инструмент выбора |
| R | Прямоугольник |
| C | Круг |
| E | Овал |
| T | Треугольник |
| D | Ромб |
| S | Звезда |
| L | Линия |
| A | Стрелка |
| X | Текст |
| Delete | Удалить объект |
| Ctrl+Z | Отмена |
| Ctrl+Y | Повтор |
| Ctrl+S | Сохранить |
| Ctrl+O | Открыть |
| Стрелки | Перемещение объекта (Shift = x10) |
| Alt+ЛКМ | Панорамирование холста |
| Колесо | Зум |
| Двойной клик | Редактировать текст |

## Сборка

### Требования
- [Node.js](https://nodejs.org/) v18+
- npm

### Шаги

```bash
# 1. Установить зависимости
npm install

# 2. Запустить для разработки
npm start

# 3. Собрать portable .exe
npm run build
```

После сборки файл `DrawApp-portable.exe` появится в папке `dist/`.

### Запуск с флешки
Просто скопируйте `DrawApp-portable.exe` на флешку и запускайте двойным кликом — установка не нужна.
